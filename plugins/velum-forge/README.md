# Velum Forge 3D Studio Plugin (v1.2)

Official **Velum Forge** bundle for Google Antigravity, Claude Code, Cursor, and Codex.

## Included Capabilities
- **Always-On Rules (`rules/AGENTS.md`):** Enforces perspective-first reference camera matching (reserving ortho grids strictly for ortho blueprints), real-world meter scale & multi-datum grounding, split-before-decimate `> 20k` instancing, BVH shell-clipping verification, 10-view automated QA (`--profile game` / `--profile roblox`, `0` errors, `0` warnings), **optional Iterative Visual Critic & Honest Rating Reviews**, Blender 5.2+/5.3 safety + hardware-safe GPU-only Cycles baking, dedicated `2048x2048` per-set PBR maps, and instance-aware `LOD0`–`LOD3` chains.
- **`velum-3d-workflow`:** Master 6-stage runbook + archetype routing + optional Stage 4B Honest Rating Critique Loop (`vforge review`).
- **`velum-architecture-environments`:** Production standard for landmarks, restaurants, commercial interiors, structured quad-flow hospitality furniture, streetscapes, signage & 3D botanicals.
- **`velum-cad-brep`:** Precision OpenCascade `build123d` mechanical CAD hardware (`STEP` + watertight `1:1 m` `GLB`) and B-Rep vs. quad-flow routing.
- **`velum-pbr-bake-lods`:** Dedicated `2048x2048` Cycles `OPTIX` PBR per-set texture baking (`isolate_for_ao`, Dual-UV `GraphicUV`, UV clamp-before-nudge, atomic `fsync`), single-pack variants, and instance-aware LODs.
- **`velum-organic-species`:** Closed `S^2` manifold organic/creature/fish modeling, signed-volume outward normal enforcement, polar eye UVs, and analytical swim rigging.
