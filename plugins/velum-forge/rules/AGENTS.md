# Velum Forge 3D Asset Engineering Rules

Whenever creating, refining, baking, optimizing, or exporting 3D models (`.blend`, `.glb`, `.fbx`, `.step`, `build123d`, or `bpy` scripts), follow the **Velum Forge 6-Gate Standard**:

1. **Activate the Relevant Velum Forge Skill First**:
   - Read `velum-3d-workflow` for any end-to-end 3D asset request (`--profile game` for buildings/high-poly vs `--profile roblox` for `<20k`/part budgets).
   - Read `velum-architecture-environments` for buildings, restaurants, interiors, streetscapes, furniture, signage, and realistic 3D botanicals.
   - Read `velum-cad-brep` for mechanical/hard-surface hardware (`build123d` B-Rep CAD) — never use B-Rep Delaunay tessellation where `FIXED` quad-flow (`Alt+J` / SubD / `UNSUBDIV`) is required.
   - Read `velum-organic-species` for creatures, fish, animals, or organic characters.
   - Read `velum-pbr-bake-lods` whenever baking procedural shaders to dedicated `2048x2048` per-set PBR textures, generating variants, or building instance-aware LODs.
2. **Perspective-First Reference Matching (Use Ortho Grids Strictly for Ortho Blueprints)**:
   - Never force orthographic blueprint planes or ortho grids onto real-world perspective photos (Street View, 3/4 shots, close-ups, aerials).
   - For **perspective photos**, mount matched Blender perspective cameras (`vflib.refs.load_references()` or `refs.add_perspective_ref_camera()` with matching `lens_mm` and eye height) so `vforge qa` renders multi-angle side-by-side `ref_comparison.png` pairs through the exact matching lens.
   - Use `1:1 m` orthographic planes and optional `--ortho-grid` metric overlays **only** when the reference image is an actual orthographic blueprint (`ortho_side`, `ortho_front`, `ortho_back`, `ortho_top`).
3. **Real-World Scale, Multi-Datum Grounding & Linked Instancing**:
   - Model strictly in **meters** (`1 unit = 1.0 m`, `+Y` forward, `+Z = Up`, `scale = (1, 1, 1)`). Single assets rest at `Z = 0.0000 m`; buildings/environments lock floors/sidewalks/balconies (`Z_ROAD`, `Z_SW`, `Z_FLOOR_INT`). Keep repeating props as **linked `Mesh` instances** (`vf_asset_set`, `vf_instanced = True`), translate elevations safely via `vflib.geo.ground_objects_safe`, and **split `> 20k`-tri merged objects (e.g., 2+ joined stools/chairs) into separate linked instances or sub-parts FIRST** before ever lowering polygon detail.
4. **Zero Shell Clipping, Joint Locks, Clearances & Watertight Topology**:
   - Never extrude interior bulkheads, lockers, fins, or tubes blindly through curved outer shells or collars. Clamp interior geometry inside shells/T-collars, keep `2D` obstacle clearances, run `deconflict_botanical_islands`, enforce positive per-island **exact 3D signed volume** normals ($\sum \frac{1}{6} v_0 \cdot (v_1 \times v_2) > 0$), keep walls `>= 1.6 mm`, and triangulate quad-flow props with `quad_method="FIXED"` (`>= 80%` `Alt+J`).
5. **Mandatory 10-View Visual & Geometric QA Gate (`PASS` with `0` Errors, `0` Warnings)**:
   - Run `vforge qa <asset>` (`--profile game --max-tris 300000` for standard architecture, `--profile game --high-poly --max-tris 0` ONLY when opt-in **High-Poly Uncapped Mode** is toggled/requested in the prompt, or `--profile roblox` for `<20k`/part) and **visually inspect** `contact_sheet_material.png`, `contact_sheet_diagnostic.png`, and multi-angle `ref_comparison.png` before declaring geometry complete.
6. **Optional Iterative Critic & Strict Always-10/10 Rating Loop (`review_loop.enabled` / when requested)**:
   - When **enabled**, archive each pass (`vforge qa ... --snapshot-iteration`), compare every render directly against all reference photos + `qa_report.json`, and log a brutally honest **Iteration N Review — Honest Rating: X.X / 10** via `vforge review log` (no grade inflation, never rush or fake scores, ratings hard-capped on QA errors/warnings/unresolved defects). **NEVER stop, approve, or proceed to Stage 5 below `10.0 / 10`** (`0` QA issues, `0` unresolved defects — even `9.5` or `9.6` must keep iterating!). When opt-in **High-Poly Uncapped Mode** (`--high-poly --max-tris 0`) is toggled or requested, use News Cafe ArchViz floors (`24–36` segs furniture/rings, `16–24` segs tableware, `12–16` segs + `substeps=3` tubes, `bevel`, `style="quatrefoil"`, dense 3D palms/foliage), never slash segments to chase a tri limit, and treat `<= 10`-seg hero props as `[MAJOR]` defects blocking `10/10`.
7. **True Cycles GPU (`OPTIX`/`CUDA`) Dedicated `2048x2048` Per-Set PBR Baking**:
   - Partition large scenes by `vf_asset_set` and bake **each set onto its own `2048x2048` (2K)** 6-map atlas (`Color` `sRGB` + `Normal`, `Roughness`, `Metalness`, `AO`, `ORM` `Non-Color`) with `isolate_for_ao=True`, Dual-UV `GraphicUV`, clamp-before-nudge UVs, atomic `render_still_safe`, and **strictly GPU-only `vflib.bake.enable_cycles_gpu(sc)`** (`d.use = (d.type == dev_type)`, GPU denoiser, `FIXED` <= 8 threads, `512 px` tiling, `1.0 s` cooldown).
8. **Single-Pack Variants, Instance-Aware `LOD0`–`LOD3` & Clean Export**:
   - Reuse one `UVMap` per `vf_asset_set` across variants, generate instance-aware `LOD0`–`LOD3` (`1.0 / ~50% / ~25% / ~10%`, `delimit={'UV', 'SEAM', 'SHARP'}`, planar `DISSOLVE` on flat glass/awnings) verified on `lod_comparison_sheet.png`, export per-set `TEXTURE_SETS`, and restore all `_src` Outliner names.
