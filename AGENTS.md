# AGENTS.md — Velum Forge Universal AI Operating Rules

This repository (**Velum Forge v1.2**) defines the standard AI-driven 3D engineering workflow used across **Google Antigravity**, **Claude Code**, **Codex**, and **Cursor**.

## Core Directives for AI Agents

1. **Read the Bundled Skills Before Writing 3D Code:**
   - [`plugins/velum-forge/skills/velum-3d-workflow/SKILL.md`](plugins/velum-forge/skills/velum-3d-workflow/SKILL.md) — Master 6-stage pipeline + `--profile game` vs `--profile roblox` routing + optional Iterative Honest Rating Loop.
   - [`plugins/velum-forge/skills/velum-architecture-environments/SKILL.md`](plugins/velum-forge/skills/velum-architecture-environments/SKILL.md) — Landmarks, restaurants, interiors, hospitality furniture, streetscapes, signage & 3D botanicals.
   - [`plugins/velum-forge/skills/velum-cad-brep/SKILL.md`](plugins/velum-forge/skills/velum-cad-brep/SKILL.md) — `build123d` OpenCascade B-Rep mechanical hardware -> `1:1 m` GLB (and when to choose structured quad-flow `bmesh` instead).
   - [`plugins/velum-forge/skills/velum-organic-species/SKILL.md`](plugins/velum-forge/skills/velum-organic-species/SKILL.md) — Closed `S^2` organic/fish/creature manifolds, polar jewel eyes & swim rigs.
   - [`plugins/velum-forge/skills/velum-pbr-bake-lods/SKILL.md`](plugins/velum-forge/skills/velum-pbr-bake-lods/SKILL.md) — Cycles `OPTIX` `2048x2048` dedicated per-set PBR baking, `isolate_for_ao`, Blender 5.2+/5.3 traps & instance-aware 4-tier LODs.
   - [`docs/BLENDER_52_GOTCHAS.md`](docs/BLENDER_52_GOTCHAS.md) — Critical API, color-space, UV clamp-before-nudge & hardware-safe bake traps in Blender 5.2+/5.3.

2. **Match Reference Mode to Reference Type (Perspective vs. Ortho Blueprint):**
   - **Real Perspective Photos (Street View, 3/4, close-ups, aerials):** Mount matched Blender perspective cameras (`vflib.refs.load_references` / `refs.add_perspective_ref_camera`) with matching `lens_mm` so `vforge qa` generates a multi-angle paired `ref_comparison.png`. Never force ortho planes or ortho grids onto perspective photos!
   - **Orthographic Blueprints (`ortho_side`, `ortho_front`, `ortho_top`):** Use `1:1 m` orthographic planes and opt-in `--ortho-grid` strictly on orthographic elevation views.

3. **Never Skip the 6 Engineering Gates (+ Optional Gate 4B Critic Loop):**
   - **Gate 1 (Real Scale, Multi-Datum Grounding & Linked Instancing):** `1.0 unit = 1.0 m`, `+Y` forward (`vflib` convention), `+Z` up, `scale = (1, 1, 1)` applied. Anchor floors/sidewalks/balconies to explicit datums (`Z_ROAD`, `Z_SW`, `Z_FLOOR_INT`), keep repeating assets as linked instances (`vf_asset_set`, `vf_instanced = True`), split `> 20k`-tri merged objects (e.g., 2+ joined stools/chairs/props) into separate linked instances or sub-parts before ever lowering poly detail, and shift elevations safely via `vflib.geo.ground_objects_safe`.
   - **Gate 2 (Hybrid CAD + Structured `FIXED` Quad-Flow BMesh):** Use `build123d` (`engine/cad/cad_bridge.py`) for machined/cast hardware and structured quad-flow `vflib.geo` / `vflib.quadflow` (`FIXED`-diagonal tris passing `>= 80%` `Alt+J`, SubD & `UNSUBDIV`) for hero furniture, tableware, frames, hulls, organic forms, and 3D curved botanicals (`t_half >= 0.80 mm`).
   - **Gate 3 (BVH Shell-Integrity, Clearances & Signed-Volume Normals):** Clamp interior structures strictly inside outer shells, run `deconflict_botanical_islands`, verify `0` shell breaches, `0` floating parts, and positive per-island signed volume (`vflib.integrity.ensure_positive_signed_volume` / `vflib.quadflow.ensure_all_islands_outward`).
   - **Gate 4 (10-View Visual & Geometric QA):** Run `vforge qa <script_or_model> --profile game --forward-axis +Y --max-tris 300000` (standard architecture), `--profile game --high-poly --max-tris 0` (when opt-in **High-Poly Uncapped Mode** is toggled or requested), or `--profile roblox` (`<20k`/part), and visually inspect `contact_sheet_material.png`, `contact_sheet_diagnostic.png`, and multi-angle `ref_comparison.png` until **`PASS (Errors: 0, Warnings: 0)`**.
   - **Gate 4B (Optional Iterative Critic & Strict Always-10/10 Rating Loop):** When `review_loop.enabled` is active (via `--iterate`, `--rate-to-10`, Studio toggle, or user prompt), snapshot each pass (`--snapshot-iteration`), rate honestly (`0.0–10.0` with no grade inflation + automatic QA/defect caps) via `vforge review log`, and **NEVER approve, accept, or proceed to Stage 5 below `10.0 / 10`** (`0` QA errors, `0` QA warnings, `0` unresolved defects — e.g., `9.0`, `9.5`, `9.6` must keep iterating!). When **High-Poly Uncapped Mode** is active, NEVER slash radial segments (`24–36` hero furniture/rings, `16–24` tableware/bottles, `12–16` + `substeps=3` tubes, `bevel`, `style="quatrefoil"` breeze blocks, `20–24`-seg palms w/ `14–18` fronds × `16–22` `3`-seg leaflet pairs) to chase a tri limit; faceted low-segment (`<= 10` segs) hero props block `10.0 / 10`.
   - **Gate 5 (Cycles `OPTIX` Dedicated `2048x2048` Per-Set PBR Baking):** Bake each `vf_asset_set` onto its own `2048x2048` (2K) 6-map atlas (`Color` `sRGB` via `lin_arr_to_srgb` + OpenGL `Normal`, `Roughness`, `Metalness`, `AO`, `ORM` `Non-Color`) using `enable_cycles_gpu` (GPU-only + GPU denoising + atomic `fsync`), `isolate_for_ao=True`, `GraphicUV` preservation, and clamp-before-nudge UV hygiene.
   - **Gate 6 (Single-Pack Variants, Instance-Aware `LOD0`–`LOD3` & Clean Export):** Reuse one packed `UVMap` across variants, generate instance-aware `LOD0`–`LOD3` (`100% / ~50% / ~25% / ~10%`, planar `DISSOLVE` on flat glass/awnings) verified on `lod_comparison_sheet.png`, export per-set `TEXTURE_SETS` in `.studio_setup.luau`, and restore all `_src` Outliner suffixes.
